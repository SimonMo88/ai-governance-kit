# Audit one folder

Use this mode only when the user identifies one folder. Read and follow
[audit.md](audit.md).

Recursively inventory every eligible file in the resolved folder. Identify its
public entry points, inbound and outbound dependencies, tests, owner boundaries,
and focused validation. Files outside the folder are read-only context unless
the user separately approves expanding the target.

The report must state complete eligible-file coverage or list exact unreviewed
files or groups. Build the preview around cohesive responsibilities rather than
mechanical file-by-file rewriting.
